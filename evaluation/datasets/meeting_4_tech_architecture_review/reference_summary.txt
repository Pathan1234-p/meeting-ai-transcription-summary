Vikram and Maya conducted a technical architecture review to evaluate event brokers for high-throughput telemetry. With peak traffic exceeding 75,000 events per second, RabbitMQ experienced CPU bottlenecks. The team decided to adopt Apache Kafka with 32 partitions and decided to set the Redis cache TTL to 3,600 seconds. Maya committed to configuring the Kafka cluster with a replication factor of 3 by Wednesday, while monitoring consumer group rebalancing latency in Datadog remains an unassigned action item.
